## Этап 1. Автозапуск с загрузкой хоста
- [ ] Юнит уже есть (`yt-dll.service`); установить в `~/.config/systemd/user/`
- [ ] `systemctl --user daemon-reload + enable`
- [ ] Проверить linger (`loginctl show-user`); если off — зафиксировать ручной шаг

## Этап 2. Пауза / продолжение
- [ ] `paused` в state; при старте сервера принудительно `paused=true`
- [ ] Воркер не берёт новые задачи на паузе
- [ ] Пауза убивает текущий yt-dlp (process group, .part остаётся) → задача назад в `queued`
- [ ] `POST /api/pause`; SIGTERM/SIGINT гасит дочерний процесс
- [ ] Кнопка Пауза/Продолжить в Очереди, иконка ⏸/▶ отражает состояние + баннер

## Этап 3. Докачка с того же места
- [ ] Явные флаги yt-dlp: `--continue`, `--retries 10`, `--fragment-retries 10`, `--socket-timeout 25` (уже)
- [ ] Проверка: .part resume после kill/рестарта

## Этап 4. Плейлист №1 (Playlist_1, постоянный)
- [ ] `permanent:true`, запрет удаления через API, замок 🔒 в UI
- [ ] После каждой ручной загрузки — append id в конец Playlist_1
- [ ] Live-плеер плейлиста: добрасывание новых без перезагрузки/прерывания
- [ ] `ended` → автоплей следующего; если следующего нет — режим ожидания и автостарт по прибытии

## Этап 5. Просмотрено → автоочистка + флаг «не удалять»
- [ ] `POST /api/watched` (ended в плеере Playlist_1/Подписки) → `watched_at`
- [ ] Janitor раз в 60с: −30 мин → убрать из плейлиста; −24 ч → удалить файл+запись (кроме `keep:true`)
- [ ] Кнопка 📌 «не удалять» на карточках + обратный отсчёт в UI
- [ ] Ручная пометка «просмотрено» (кнопка), чтобы таймеры тикали без досмотра до конца

## Этап 6. Кнопка скачивания файла на устройство
- [ ] `?dl=1` в `/videos/` → `Content-Disposition: attachment`
- [ ] Кнопка ⬇ в списке загруженных (работает по LAN с мобильного)

## Этап 7. Раздел «Каналы»
- [ ] Модель `channels[]`: url, name, interval_min, max_videos, enabled, last_check
- [ ] Реестр `seen{video_id}` — переживает удаление файлов (защита от повторной загрузки)
- [ ] Скан `yt-dlp --flat-playlist --playlist-end N`, unseen newest max_videos → в очередь (`source=channel`)
- [ ] Автозагруженное → в конец «Подписки» (пересоздать, если удалён); та же очистка по просмотру
- [ ] Бейдж «авто» в Очереди/Загруженных
- [ ] Вкладка Каналы: add/list/enable/interval/«проверить сейчас»/delete
- [ ] Фильтры Очередь/Загруженные: все/ручные/авто + сортировка (дата загрузки, дата публикации, название, размер)
