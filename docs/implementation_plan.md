# План реализации (Implementation Roadmap)

Этот документ описывает этапы превращения `yt-dll` из консольного/веб-приложения в полноценную домашнюю медиасистему с поддержкой Android TV.

## Этап 1: Быстрый старт (Простой доступ через SMB)
**Цель:** Начать смотреть скачанные видео на ТВ без сложной настройки сервера.

1. **Настройка хоста (где лежит yt-dll):**
   - Установить и настроить `Samba` (SMB).
   - Расшарить папку `videos/` в локальную сеть (режим Read-Only для безопасности).
   - Настроить скрытие файлов `.part`, чтобы ТВ не пытался играть недокачанные видео.
2. **Настройка клиента (Android TV / Смартфон):**
   - Установить **VLC for Android**.
   - Подключиться к SMB-шаре по IP хоста.
3. **Дополнение в коде (yt-dll):**
   - Реализовать экспорт логических плейлистов (`Playlist_1`, `Подписки`) в файлы `.m3u` прямо в папку с видео. Это позволит VLC видеть "список воспроизведения".

## Этап 2: Полноценная медиабиблиотека (Jellyfin + Docker)
**Цель:** Получить красивый интерфейс с постерами, описаниями и удобным поиском на ТВ.

1. **Подготовка RPi5:**
   - Установка Docker и Docker Compose.
   - Подключение внешнего хранилища (HDD/SSD).
2. **Развертывание Jellyfin:**
   - Создать `docker-compose.yml` для Jellyfin.
   - Настроить монтирование папки с видео как Read-Only (`:ro`).
3. **Настройка интерфейса:**
   - Установка приложения **Jellyfin for Android TV**.
   - Настройка библиотеки в Jellyfin (тип "Videos", без автопоиска метаданных из интернета, чтобы использовать имена файлов).

## Этап 3: Автоматизация и синхронизация
**Цель:** Сделать систему полностью автономной ("загрузил и забыл").

1. **Синхронизация статуса просмотра:**
   - Реализовать передачу события "видео досмотрено" из Jellyfin в `yt-dll` (через Webhook или API), чтобы запускался таймер на удаление файла/убирание из плейлиста.
2. **Улучшение метаданных:**
   - Добавить автоматическое скачивание обложек (`thumbnails`) через `yt-dlp` для всех видео, чтобы Jellyfin видел картинки даже без интернета (через локальную папку).

## Примечания по оборудованию
- **RPi5** рекомендуется использовать с **NVMe HAT**, так как база данных медиасервера любит быстрые диски.
- Для Android TV критически важен качественный Wi-Fi или Ethernet, чтобы избежать фризов при просмотре тяжелых файлов (хотя H.264 720p идет легко).
